# About game
In Escape the Mansion!, you need to escape a house (thus the title) and more.
# Controls
Use your mouse or drag with touch to move the camera, WASD or arrow keys to move the player, and Esc (P for WebGL) to return to the menu while in-game. To collect or interact with an object, touch it with your character.
